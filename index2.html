Telecomunicaciones

Las telecomunicaciones son el conjunto de tecnologías, sistemas y medios que permiten transmitir información a distancia. Esa información puede ser voz, datos, imágenes o videos, utilizando señales eléctricas, ópticas o de radio. Algunos ejemplos cotidianos de telecomunicaciones son: Las llamadas telefónicas. El acceso a Internet. Los mensajes de texto (SMS) y aplicaciones de mensajería. La televisión y la radio. Las videollamadas. Para que una comunicación ocurra, generalmente intervienen estos elementos: Emisor: quien envía la información. Mensaje: la información que se transmite. Medio o canal: por donde viaja la información (fibra óptica, cable, ondas de radio, satélites, etc.). Receptor: quien recibe la información. Las telecomunicaciones son fundamentales porque facilitan la comunicación entre personas y organizaciones, apoyan la educación, la salud, el comercio, la seguridad y el entretenimiento, y permiten la conexión global a través de Internet.

Redes Lan

Red de bus

Una red en bus es una topología de red donde todos los dispositivos están conectados directamente a un único cable central llamado bus, troncal o backbone

red de anillo

Una red en anillo es una topología de red donde cada dispositivo o nodo se conecta a otros dos, formando un círculo o bucle cerrado.

Red de estrella

Una Red en estrella es una topología de red donde todos los dispositivos se conectan de forma independiente a un punto o nodo central, como un conmutador (switch), enrutador (router) o concentrador (hub).

Doble anillo

La topología de doble anillo es una configuración de red que utiliza dos anillos concéntricos independientes para conectar los mismos dispositivos, donde un anillo sirve para la transmisión normal de datos y el segundo actúa como respaldo o redundancia.

Red de arbol

Una red en árbol es una Red en árbol en la que los dispositivos se organizan en forma de jerarquía ramificada, parecida a un árbol invertido.

Red de malla

Una red en malla es un sistema donde los dispositivos o nodos se conectan entre sí de forma descentralizada, creando múltiples caminos para que viajen los datos.

red mixta

Una red mixta (o topología híbrida) es una red de computadoras que combina dos o más topologías de red diferentes, como estrella, bus, anillo o malla.

Red totalmente conexa

Una red totalmente conexa (también conocida como topología de malla completa) es una estructura donde cada dispositivo o nodo está conectado de forma directa a todos los demás.
